# Getting started

1. Install this entire folder, including `references/`, using your assistant's supported skill installation method.
2. Give the assistant a Figma frame link or redacted screenshot, and say whether it is a native app or mobile webapp.
3. Ask it to use `iphone-duo-check`.
4. Review the pose findings and choose a layout option.
5. Confirm the exact Figma frame and give permission before it creates edited copies.

The workflow aims to preserve your screen's content and visual style while adapting its layout. Figma editing requires an editing-capable connection and access to the file. Claude uses Artifacts to present the findings and options. OpenAI environments, including ChatGPT and Codex, use Sites, private by default. These tools must be available in your assistant environment. If the appropriate tool is unavailable, the assistant explains the limitation and presents the findings and options in chat.

Before relying on device-specific findings, verify the bundled source links, geometry and component keys against the live guidance and kit. If a required tool or source is unavailable, ask the assistant to explain the limitation before continuing.

Use test data or redact private information in screenshots.
